# AI 对话

## 功能概述

学氧助手的 AI 对话功能支持多模型、多会话、流式响应。

## 支持的模型

| 模型 | 上下文长度 | 特点 |
|------|-----------|------|
| GLM-5 | 1M | 超长上下文，适合长文档分析 |
| Qwen-Plus | 200K | 综合能力强，性价比高 |
| DeepSeek-Chat | 128K | 代码能力强 |
| Doubao-Seed | 128K | 豆包模型 |

## 使用方式

1. 登录后进入对话页面
2. 选择模型和会话
3. 输入问题，AI 流式返回
4. 支持 Markdown、代码高亮、Mermaid 图表渲染

## 技术实现

- 基于 LangChain `ChatOpenAI` 统一接口
- 使用 SSE 协议实现流式传输
- 前端原生 `fetch` + `ReadableStream` 解析
- 上下文自动压缩（超过模型限制 80% 时触发）
