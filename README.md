# 学氧科技

> **让学习像呼吸一样自然**  
> **终身学习助手**

## 关于我们

**学氧科技** 是一个专注于教育科技的创新项目，我们的使命是通过人工智能技术，为每一位学习者提供个性化、智能化的学习支持。

### 核心理念

- **学无止境** - 终身学习是通往成功的必经之路
- **氧气般自然** - 让学习像呼吸一样自然、不可或缺
- **科技赋能** - 用 AI 技术打破传统教育的边界

## 项目现状

当前平台是 **个人技术学习成果的展示平台**，集成了多种 AI 能力和实用工具：

### 核心功能

| 模块 | 功能描述 |
|------|----------|
| 🤖 **AI 对话** | 基于大模型的智能问答系统 |
| 📝 **备忘录** | 智能笔记管理与知识整理 |
| 📄 **简历优化** | AI 辅助简历撰写与优化 |
| 📊 **数据分析** | 学习数据可视化与统计 |

### 技术栈

**前端**
- Vue 3 + Vite
- Element Plus UI 组件库
- Vue Router 路由管理

**后端**
- Python + FastAPI
- JWT 身份认证
- LangGraph 工作流编排
